# 매물 홍보 비서

입력된 매물 정보를 조합해 블로그, SNS, 소개 카드 문구, 30초 세로 영상 대본을 만드는 한국어 웹앱입니다. 외부 라이브러리와 AI 키 없이 실행할 수 있습니다.

## 실행

Node.js가 설치된 환경에서 이 폴더의 터미널을 열고 실행합니다.

```sh
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다. 정적 호스팅에는 `dist` 폴더를 사용합니다. ES 모듈을 사용하므로 HTML을 파일 탐색기에서 직접 여는 대신 HTTP 서버를 사용하세요.

## 검증

```sh
npm test
```

## 구조

- `dist/index.html`: 입력 화면과 결과 화면
- `dist/styles.css`: 반응형 레이아웃과 스타일
- `dist/app.js`: 폼, 채널 전환, 복사, 다운로드
- `dist/generator.js`: 정규화·주소 공개 처리·콘텐츠 생성. 향후 서버 AI 어댑터로 교체할 수 있는 순수 함수
- `server.mjs`: 의존성 없는 로컬 정적 서버
- `tests/generator.test.mjs`: 주소 공개, 빈 값, 거래 유형, 가상 예시 등 핵심 규칙 검증

## 현재 기능

- 7종 매물, 3종 거래, 3종 문체와 콘텐츠 형식 4종
- 입력하지 않은 항목 생략, 거래 유형별 가격 분리
- 상세 주소·호수 기본 비공개, 명시적으로 선택한 경우만 공개
- 지역란에 섞인 도로명·숫자 상세 주소를 보수적으로 제외
- 추가 확인 사항은 홍보 본문·복사·다운로드에서 제외하고 별도 표시
- 가상 예시는 제목·본문·내보내기에도 표시
- 수정 후 기존 결과에 갱신 안내, 탭 전환 시 생성 당시 정보 유지
- 클립보드 복사 및 권한 제한 시 수동 복사 창
- UTF-8 TXT 다운로드

## 아직 연결되지 않은 기능

AI 생성, 로그인·DB 저장, 공공데이터 조회, 사진 업로드·카드 이미지 출력, 실제 영상·음성 생성, SNS 게시 기능은 없습니다. 영상 탭은 시간 구간별 텍스트 대본만 만듭니다. 폼의 내용은 메모리에만 유지되고 새로고침하면 사라집니다.

공개할 지역과 자유 입력란에는 공개 가능한 정보만 입력하세요. 주소 보호는 전용 상세 주소란과 지역란에 적용되며, 임의의 문장 안에 들어 있는 모든 개인정보를 자동으로 판별하는 기능은 아닙니다. 사실 검증은 하지 않으므로 게시 전에 입력 정보와 필요한 표시 사항을 확인해야 합니다.
