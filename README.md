# 매물 홍보 비서 v2.2

매물 정보를 이용한 템플릿 / 실제 AI 홍보 문구 작성 도구입니다. 블로그, SNS, 소개 카드, 30초 세로 영상 대본을 지원합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```sh
pnpm install --frozen-lockfile
# .env.example을 .env.local로 복사하고 편집기에 자신의 키를 입력
pnpm dev
```

npm 사용 시 `npm install` 후 `npm run dev`로 실행할 수 있습니다. http://127.0.0.1:4173 을 엽니다. 키 없이도 템플릿은 동작합니다. HTML을 직접 여는 방식은 서버 API를 사용할 수 없습니다.

## AI 환경변수

| 이름 | 용도 |
| --- | --- |
| OPENAI_API_KEY | 실제 OpenAI API 키. 서버에서만 읽음 |
| OPENAI_MODEL | 계정에서 사용 가능한 Responses/구조화 출력 모델. 기본 gpt-6-luna |
| PORT | 로컬 포트. 기본 4173 |

[OpenAI 키 발급](https://platform.openai.com/api-keys)

실제 키를 채팅, GitHub, 브라우저 JavaScript 또는 로그에 붙여넣지 마세요. `.env.local`은 Git에서 제외됩니다. `.env.example`만 공유합니다. 키 수정 후 로컬 서버를 재시작하세요. API 사용은 연결 계정의 사용량에 반영됩니다.

## Vercel 배포

GitHub `harunangman-lab/agent1`을 연결합니다. 저장소 루트, Framework Other, Output Directory `dist`, Build Command 빈칸을 사용합니다. Install Command는 기본값으로 두고 설치를 생략하지 마세요.

`vercel.json`에 정적 경로가 설정되어 있고 루트 `api/*.js`는 Node.js Functions입니다. `dist`만 별도로 올리면 AI 서버가 빠지므로 전체 프로젝트를 배포해야 합니다.

Vercel Project Settings → Environment Variables에서 `OPENAI_API_KEY`를 Sensitive 값으로 저장하고 `OPENAI_MODEL`을 설정합니다. 사용할 Production/Preview 환경을 지정한 뒤 Redeploy하세요. 실제 키는 GitHub에 넣지 않습니다.

배포 후 `/api/config`의 `configured`로 변수 존재 여부를 확인할 수 있습니다. 키·잔액·모델 권한의 유효성을 보장하는 검사는 아닙니다. 실제 AI 생성 성공으로 확인해야 합니다. 예전 ChatGPT Sites 정적 배포에는 Vercel Functions 구성이 자동 반영되지 않습니다.

## 동작

- 템플릿은 브라우저에서, AI 생성은 서버에서 OpenAI Responses API를 호출합니다.
- AI SDK 구조화 출력을 사용하고 `store:false`를 설정합니다. 입력·출력·키를 로그에 기록하지 않습니다.
- 결과는 모드/콘텐츠 유형별로 보관하여 전환해도 수정본이 유지됩니다.
- 제목·본문·문의 문구를 수정할 수 있고 복사·TXT는 현재 수정본을 사용합니다.
- 작성 중 입력과 버튼을 잠그고 중복 요청을 막습니다. 실패하면 입력과 이전 결과를 유지하고 수동 재시도를 제공합니다. 템플릿으로 몰래 대체하지 않습니다.
- 사용한 정보와 확인 사항은 접이식으로 표시합니다. 확인 사항은 홍보 본문·AI 입력·내보내기에서 제외됩니다.

## 데이터 처리와 검증 범위

허용된 입력 항목만 처리하고 상세 주소는 공개 선택 시에만 사용합니다. 전화번호·이메일·고객/소유자 표시·지시문 패턴을 감지해 해당 줄을 제외합니다. 사무소와 홍보용 연락처는 모델에 보내지 않고 서버가 문의 문구에 붙입니다.

모델은 입력 사실 ID를 인용하고 제공된 해시태그만 사용합니다. 서버는 응답 형식, 사실 ID, 미입력 숫자, 개인정보 및 일부 과장 표현을 검사합니다. 모든 의미상의 허위 사실이나 개인정보를 판별하는 기능은 아닙니다. 게시 전 원자료와 대조하세요. 직접 수정한 결과는 자동 사실 검증하지 않습니다. 영상은 대본만 만듭니다.

20KB 요청 제한, 45초 AI 타임아웃, 동일 클라이언트 동시 요청 제한, 인스턴스당 10분 8회 제한을 적용합니다. 이 제한은 서버리스 인스턴스 간 공유되지 않으며 인증·결제·분산 요청 제한을 대체하지 않습니다.

## 구조

- `dist/`: 화면, 편집, 템플릿, 공개 데이터 정리
- `lib/ai-service.js`: 서버 AI 호출·응답 검사
- `lib/http-api.js`: 로컬/Vercel 공통 API
- `api/config.js`, `api/generate.js`: Vercel Functions
- `server.mjs`: 로컬 정적 서버·API·환경변수 로드
- `.env.example`: 빈 키와 모델 설정 예시
- `tests/`: 개인정보, SDK 요청/응답, 오류·중복 요청 검증

## 검증

```sh
pnpm test
```

SDK 성공/오류 테스트는 외부 호출을 가로채는 fixture를 사용하며 실제 키를 요구하지 않습니다. 실서비스 AI 호출 성공을 의미하지 않습니다. 실제 호출 검증에는 유효한 키와 모델 접근 권한이 필요합니다.

참고: [OpenAI 구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs), [Vercel Node.js Functions](https://vercel.com/docs/functions/runtimes/node-js).

## 매물 사진과 홍보 카드

화면 아래 사진 스튜디오에서 여러 사진을 선택하거나 끌어다 놓습니다. JPG·PNG·WebP, 장당 10MB, 최대 10장, 합계 50MB, 장당 4,000만 화소까지 지원합니다. HEIC·GIF·SVG는 지원하지 않습니다. 같은 파일의 중복 추가와 손상된 사진은 안내 후 제외합니다.

사진마다 미리보기, 대표 사진 선택, 거실·주방·방·욕실·외관·기타 분류, 위아래 순서 변경, 목록 삭제를 제공합니다. 원본 File은 그대로 유지하고 회전·비율·확대·좌우/상하 위치·밝기 설정을 별도로 저장합니다. 원본 다운로드와 편집본 PNG 다운로드는 별개입니다. 삭제는 브라우저 목록에서만 지우며 디스크 원본은 삭제하지 않습니다.

편집은 90도 단위 회전, 16:9·4:3·1:1·원본 비율 자르기, 1–3배 확대, 50–150% 밝기를 지원합니다. 내부 작업용 이미지는 긴 변 최대 1600px로 줄입니다. 구조·하자·시설을 바꾸는 생성 편집은 없습니다. 카드의 사진 영역에 맞춰 편집본을 가운데 기준으로 추가 자를 수 있습니다.

매물 정보를 입력하고 대표 사진을 정한 뒤 ‘홍보 카드 만들기’를 누르세요. 정사각형 1080×1080 또는 세로형 1080×1350을 선택하고 제목·가격·면적·확인된 특징을 직접 수정할 수 있습니다. 사무소와 홍보용 연락처는 매물 입력란에서 가져옵니다. 주소와 연락처 공개 선택은 문구와 카드에 함께 적용합니다. 매물 정보를 바꾸면 카드에 갱신 안내를 띄우고 다시 생성할 때까지 다운로드를 막습니다.

한글 줄바꿈과 글자 축소로 공간을 맞추고, 최소 크기에서도 담기지 않는 내용은 자르거나 생략하지 않고 오류로 안내합니다. 미리보기 이미지는 완성된 PNG Blob이고, 다운로드도 같은 Blob을 사용하므로 화면과 파일이 일치합니다. 사용자의 직접 입력은 게시 전에 확인해주세요.

사진 스튜디오의 사진과 카드는 서버·AI에 전송하지 않습니다. 브라우저 메모리에만 보관하므로 탭을 닫거나 새로고침하면 사진·편집 설정이 사라집니다. 영구 저장·로그인·클라우드 업로드는 아직 없습니다. 아래 캡처 정보 인식은 별도 전송 기능입니다.

관련 소스: `dist/photo-core.js` (제한·자르기·문구 배치 계산), `dist/card-renderer.js` (사진 편집·카드 렌더링), `dist/photo-studio.js` (사진 목록·편집창·다운로드), `dist/photo-studio.css`.

## 엑셀·등록 화면 캡처에서 매물 가져오기

상단 ‘등록된 매물 정보’ 영역에서 가져오세요. 원자료를 읽은 후 미리보기에서 수정·항목 선택·대조 확인을 마쳐야 본 입력란에 반영됩니다. 기존 매물 항목은 교체되며 없는 항목은 비워집니다. 사무소·홍보용 연락처·문체·사진 목록은 유지합니다. 다른 매물을 가져오면 사진도 같은 매물인지 확인하세요. 적용 시 상세 주소와 연락처 공개 선택은 해제됩니다. 가져온 특징은 직접 확인 체크를 하지 않으면 추가 확인 사항으로만 이동합니다. 캡처·엑셀 속 명령문은 실행하지 않습니다.

**엑셀**: XLSX·XLS·CSV, 파일 최대 5MB. 브라우저 Worker에서 SheetJS CE 0.20.3을 이용해 읽습니다. 앞 20개 시트, 시트별 앞 1,000행·100열로 제한하며 20초를 넘으면 중단합니다. 열 제목 행·시트·항목별 열·가져올 매물 한 행을 선택합니다. CSV는 UTF-8을 권장합니다. ‘CSV 양식 받기’는 빈 제목 행만 제공합니다. 자동 연결은 명시적인 열 이름을 사용하며 공급면적·평·일반 ‘가격’ 열은 임의 해석하지 않습니다. 제목에 (만원)/(억원)/(원)이 있는 숫자 금액에는 해당 단위를 붙입니다. 숫자를 다른 단위로 환산하지 않습니다. 수식은 계산하지 않고 저장된 값을 읽으며 링크·매크로는 실행하지 않습니다. 엑셀의 내장 사진은 가져오지 않습니다. 파일은 서버로 보내지 않습니다.

**캡처**: 동일 매물의 JPG·PNG·WebP 1~3장, 장당 5MB·4,000만 화소 이하. 고객·소유자 개인정보를 가린 캡처를 사용하세요. 전송 동의 후 인식 버튼을 누르면 긴 변 최대 2200px JPEG로 줄여 서버 API `/api/import-listing`를 통해 OpenAI에 보냅니다. 홍보 카드용 사진에는 자동 추가하지 않습니다. 서버 디스크에 저장하지 않고 `store:false`로 요청합니다. 개인정보 자동 탐지·완전한 사실 검증을 보장하지 않으므로 원자료 대조가 필요합니다. 원본 파일은 변경하지 않습니다.

기존 `OPENAI_API_KEY`, `OPENAI_MODEL`을 사용합니다. 이미지 입력·구조화 출력을 지원하는 별도 모델을 사용하려면 서버의 `OPENAI_VISION_MODEL`을 설정하세요. `.env.local` 또는 Vercel 환경변수에 넣고 서버 재시작/재배포합니다. 실제 키는 브라우저 코드에 넣지 마세요. 키 미설정·권한·할당량·모델 오류는 안내하고 입력과 캡처 선택을 유지합니다. 성공처럼 표시하거나 임의 데이터를 대신 채우지 않습니다. 실제 외부 AI 호출은 유효한 키가 있어야 합니다.

캡처 API는 JSON 3.1MB, 디코딩 이미지 총 2.2MB 제한입니다. 기존 AI 생성과 같은 인스턴스 내 중복 요청/10분 8회 제한을 적용합니다. Vercel의 서로 다른 함수 인스턴스 간에는 공유되지 않습니다. 로그인·서버 저장·다른 사이트 로그인·URL 크롤링·부동산 포털 API 연동은 포함하지 않습니다.

관련 코드: `dist/listing-import.js`, `dist/import-core.js`, `dist/excel-worker.js`, `lib/import-service.js`, `api/import-listing.js`. SheetJS 원본과 Apache 2.0 라이선스는 `dist/vendor/`에 보관했습니다. [공식 설치 문서](https://docs.sheetjs.com/docs/getting-started/installation/standalone/).
